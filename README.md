# ZephyrLens

ZephyrLens: A High-Performance, Multi-Threaded Framework Engine for Real-Time Data Processing and Auto-Scaling Dynamic Workloads.

With ZephyrLens, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ZephyrLens.git`
2. `cd ZephyrLens`
3. Install in editable mode: `pip install -e .`

## Configuration

ZephyrLens is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
